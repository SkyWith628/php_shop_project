# 🛒 shop69 — PHP 풀스택 쇼핑몰

![Image](https://github.com/user-attachments/assets/6dc48c1d-a3bf-46c3-9171-830a049d412a)

PHP(절차지향) + MySQL로 직접 구현한 **풀스택 쇼핑몰**입니다.
사용자 쇼핑 플로우(회원·상품·장바구니·주문)부터 운영자가 쓰는 **관리자 백오피스**까지, 이커머스의 핵심 흐름을 처음부터 끝까지 만들어 본 프로젝트입니다.

## ✨ 주요 기능

### 🙋 사용자
- **회원** — 가입·로그인·정보 수정, 아이디 중복 확인
- **상품** — 메인 진열, 상세 보기, 카테고리/옵션 선택
- **장바구니** — 담기·수량 수정·삭제
- **주문** — 주문서 작성, 주문 내역 조회
- **주소 검색(juso)** — 우편번호/도로명 주소 입력 보조
- **고객지원** — FAQ, 최근 본 상품(쿠키 기반)

### 🛠️ 관리자 (`/admin`)
- **상품 관리** — 등록·수정·삭제 (이미지 업로드 포함)
- **옵션 관리** — 단일/다중 옵션 CRUD
- **주문 관리** — 주문 조회·상태 변경
- **회원 관리** — 회원 목록·정보 수정·삭제
- **FAQ 관리** — 게시글 CRUD

## 🧰 기술 스택

| 분류 | 사용 기술 |
| --- | --- |
| Backend | PHP (절차지향), MySQL |
| Frontend | HTML, CSS, JavaScript, Bootstrap 5, jQuery |
| 공통 | `common.php` (DB 연결·공통 함수), 세션 기반 인증 |

## 🗂️ 구조

```
├── index.html / main.php      # 메인
├── member_*.php               # 회원
├── cart*.php                  # 장바구니
├── jumun*.php                 # 주문
├── faq*.php                   # FAQ
├── juso/                      # 주소 검색 모듈
├── common.php                 # DB 연결 · 공통 함수
└── admin/                     # 관리자 백오피스 (상품·옵션·주문·회원·FAQ)
```
